# Deterministic text fixtures

These are glyph-subset fixtures derived from the Fedora-packaged Noto Sans,
Noto Sans CJK SC and Noto Color Emoji fonts. They contain only the characters
used by the UI-2 tests, so golden images do not depend on the host's installed
font versions.

The files are modified subsets produced with fonttools. Copyright remains with
the original font authors. All three are redistributed under the SIL Open Font
License 1.1 in `OFL-1.1.txt`; no Reserved Font Names are declared by these
sources.
